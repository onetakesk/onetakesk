ONETAKE — HOTOVÝ WEB PRE GITHUB + VERCEL

1. Rozbaľ tento ZIP.
2. Nahraj priamo do koreňa GitHub repozitára súbory index.html a vercel.json.
   Dôležité: nesmú byť vo vnorenom priečinku.
3. Vo Verceli nastav projekt na tento GitHub repozitár a správnu branch.
4. Settings → Build and Deployment:
   - Framework Preset: Other
   - Root Directory: ./
   - Build Command: vypnutý / prázdny
   - Output Directory: vypnutý / prázdny
5. Ulož a sprav nový deployment.

Stránka je čisté statické HTML/CSS/JS, nepotrebuje npm install ani build.
