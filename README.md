# ONETAKE — website

Static, responsive website built with HTML, CSS and vanilla JavaScript. No build command or dependencies are required.

## Deploy to Vercel
1. Upload the contents of this project to the root of your GitHub repository.
2. In Vercel, set Framework Preset to `Other`.
3. Set Root Directory to `./` and Output Directory to `public`.
4. Leave Build Command empty and deploy.

The page is self-contained in `public/index.html`. Portfolio images currently use remotely hosted Unsplash images; replace them with your own work before presenting them as commissioned projects. They are labelled as visual studies / illustrative imagery in the page.
